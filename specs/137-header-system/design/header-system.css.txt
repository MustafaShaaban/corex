/* CoreX spec 137, the header system: the rules the kit's bundle.css does not have.
   This file is the build contract. Every class it adds starts corex-. Every value is a theme.json
   token, and every side is a logical property. The kit's own classes are used unchanged; where one
   is restyled by where it sits (inside the phone menu, inside the utility row), the selector says so.
   Raw lengths are the kit's own: 3rem (a phone menu row), 2.75rem (a target), 2.5rem (a bar link),
   2.25rem (a small button), 14rem (the Dropdown's width).
   "!important" on a link colour only answers the preview's own link rule, as bundle.css does. */
